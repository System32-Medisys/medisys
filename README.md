# Medisys

Sistema web de agendamento médico para uma clínica, desenvolvido pela Software House **System32**.

## Escopo

O sistema gerencia pacientes, médicos, atendentes, consultas, exames e resultados, aplicando permissões diferentes para cada perfil:

- Paciente;
- Atendente;
- Médico;
- Administrador.
