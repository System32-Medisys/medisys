# MedAgenda · identidade SYSTEM32

Cópia do projeto recebido, com identidade aplicada.

- Paleta derivada do azul #00AEEF e verde #00FFC8 da SYSTEM32.
- Tons mais escuros de azul para botões com texto branco.
- Assinatura SYSTEM32 no cabeçalho e rodapé.
- Símbolo vetorial simplificado inspirado na referência, não reprodução exata.
- Nome e fluxo de agendamento do MedAgenda preservados.
- Título e descrição em português; dados empresariais fictícios do rodapé substituídos por identificação acadêmica.

## Executar

Com Node.js instalado, execute `npm install` e `npm run dev`.
Para gerar a versão de produção: `npm run build`.

O agendamento e outros comportamentos de demonstração são os do projeto original. Esta alteração visual não implementa servidor, envio de mensagens ou pagamentos.
