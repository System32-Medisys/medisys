## Escopo atual

O sistema atende uma clínica médica e possui quatro perfis: Paciente, Atendente, Médico e Administrador. O controle de acesso será aplicado na interface e no servidor.

## Como manter esta documentação

- Registrar decisões importantes assim que forem tomadas;
- Identificar a data e os responsáveis por cada atividade;
- Usar Issues para distribuir as tarefas;
- Fazer commits com mensagens claras;
- Guardar diagramas e capturas de tela na futura pasta `docs/imagens`.
