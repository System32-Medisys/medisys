# Requisitos iniciais

Os requisitos abaixo representam o escopo inicial e poderão ser revisados pelo grupo durante a N1.

## Requisitos funcionais

- **RF01:** permitir o cadastro de usuários;
- **RF02:** permitir o cadastro e a atualização de pacientes;
- **RF03:** permitir o cadastro de médicos;
- **RF04:** permitir o cadastro de especialidades;
- **RF05:** permitir o cadastro de horários disponíveis;
- **RF06:** permitir que o paciente consulte horários;
- **RF07:** permitir o agendamento de consultas;
- **RF08:** permitir a confirmação de consultas;
- **RF09:** permitir o cancelamento de consultas;
- **RF10:** permitir que médicos visualizem suas agendas;
- **RF11:** permitir que a recepção gerencie os agendamentos;
- **RF12:** permitir que o administrador gerencie os usuários.

## Requisitos não funcionais

- **RNF01:** possuir interface simples e intuitiva;
- **RNF02:** funcionar em navegadores atuais;
- **RNF03:** adaptar-se a computadores e celulares;
- **RNF04:** proteger o acesso por autenticação;
- **RNF05:** armazenar os dados de maneira segura;
- **RNF06:** apresentar mensagens claras de sucesso ou erro.
