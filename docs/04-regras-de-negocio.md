# Regras de negócio

- **RN01:** uma consulta deve estar associada a um paciente e a um médico;
- **RN02:** o médico deve estar vinculado a pelo menos uma especialidade;
- **RN03:** dois agendamentos não podem ocupar o mesmo horário do mesmo médico;
- **RN04:** somente horários disponíveis podem ser agendados;
- **RN05:** consultas canceladas devem liberar o horário correspondente;
- **RN06:** somente usuários autenticados podem acessar funções restritas;
- **RN07:** cada tipo de usuário deve acessar apenas as funções autorizadas;
- **RN08:** alterações importantes no agendamento devem ser registradas;
- **RN09:** a duração e a disponibilidade dos horários serão configuradas pela clínica;
- **RN10:** novas regras poderão ser adicionadas após a validação do escopo com o professor.
